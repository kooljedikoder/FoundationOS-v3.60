Help & PRD Summary
A condensed product reference, built from the 24-file Gold Build Specification — the source of truth for this prototype.

Product Vision

One platform, multiple editions, unlimited growth. Start with Vendor Registration, expand into Procurement, scale into full Enterprise Supplier Lifecycle Management — no migration, no data conversion, no retraining between editions.

Editions at a Glance

FLEX — 8 simplified workspaces for SMEs and single-site orgs.
CORE — Modules 1–18, full Enterprise Supplier Lifecycle Management.
PLUS — adds Module 19, the standalone Enterprise Procurement Hub (Source-to-Pay).
Vendor Registration, Vendor Passport 360 and Supplier Assessment are always full — see Editions & Licensing for the full feature matrix.

Role Views

Use the profile menu (top right) to preview the sidebar as it looks for a specific role. Sections outside that role's remit are hidden — e.g. User Admin sees Dashboard and Administration only; Procurement, Finance, HSE and Collaboration are hidden since they're not part of that job.
