Contact form: unified 13 steps for all six types. One flow for registration and for the admin view, copied from the real CCC fields, labels, placeholders and options for each type. Pick a type to see its field set; steps that a type does not use are hidden. User view hides the fields only staff fill in; Admin view shows them marked ADMIN, plus the review and custom fields. Switch the page to Proposed changes to see the new declaration. Saves go to the prototype database.
