FLEX is a complete vendor lifecycle, not a reduced onboarding tier. CORE inherits every FLEX capability; PLUS inherits FLEX and CORE. Platform extensions such as VendorOS Studio operate across editions and do not replace these product tiers. This matrix defines target edition scope; it does not claim every listed feature is already implemented.

FoundationOS Implementation & Reuse Map
Current project vs. VendorOS target

Reuse what works. Build only the VendorOS gaps.

FoundationOS remains the running Laravel + Filament + ERP application. All apps use the same database. Reusable apps own shared capabilities and records; VendorOS adds supplier-specific workflow and access rules around them.
